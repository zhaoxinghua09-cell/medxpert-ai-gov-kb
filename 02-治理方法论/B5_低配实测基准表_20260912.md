# B5 · 低配 / 离线 / 免 API key —— 实测基准表与占位主张

## 四、这份数据说明了什么（给读者的一句话）

**一台没有独立显卡的普通台式机，跑 4.7B 量化模型可以稳定输出 51 tok/s —— 比人阅读速度快约 10 倍。**

换算成人能感知的粒度：

- **4B 模型**：写一封 300 字邮件 ≈ **12 秒**（128 token 用 2.6 秒）
- **9B 模型**：同样内容 ≈ **18 秒**
- **内存门槛**：4B 只需 **3.07 GB** 常驻 → **8 GB 内存的机器就能跑**；9B 需 **5.44 GB** → 16 GB 机器宽裕

**关键结论（B5 主张的事实基础）**：
> **门槛不是"有没有显卡"，而是"内存够不够装下模型"。** 4B 量化模型 3 GB 出头，八年前的老机器内存够就能跑。

## 五、主标语（可直接对外用）

> 口径纪律：**不说"最强/第一"**，只说事实与门槛；所有数字标量级并注明实测条件。

**主标语（推荐）**
> **8 GB 内存 / 无独显 / 断网可用 / 免 API key —— 老电脑跑得动的本地 AI。**

**配标语（三条，按场景取用）**

| 场景 | 文案 |
|---|---|
| 讲门槛 | 门槛不是显卡，是内存：4B 量化模型常驻 3.07 GB，8 GB 老机就能跑。 |
| 讲速度 | 无独显实测 51 tok/s（4B）/ 33.6 tok/s（9B）—— 比人读得快。 |
| 讲代价 | 零 API 费用、数据不出本机、断网可用；代价是模型规模小，复杂推理弱于云端大模型。 |

**🔴 诚实边界（必须同时出现，不可只放主标语）**
- 本机**有 32 GB 内存**，故 8 GB 可用性为**由常驻占用推导**（3.07 GB < 8 GB），非 8 GB 实机跑分。
- 4B/9B 小模型的复杂推理、长链逻辑、专业准确性**弱于云端大模型**，适合"日常文字/摘要/分类/私有数据问答"，不适合高风险决策直接采信。
- 速度受 CPU 架构与内存带宽影响；不同机器结果会差 2–3 倍，**以本机实测为准**。
