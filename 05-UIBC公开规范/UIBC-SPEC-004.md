## 第 1 章 范围与术语

### 1.1 适用范围

本规范适用于任何对智能体能力进行横向比较的评测活动，包括：

- 公开赛事（挑战赛、黑客松）
- 企业内部的智能体选型评测
- 排行榜（Leaderboard）
- 能力认证的符合性测试

不适用：无横向比较目的的单体功能测试。

### 1.2 术语定义

| 术语 | 定义 |
| --- | --- |
| 评测集（Benchmark Set） | 用于评测的标准化任务集合 |
| 公开集 | 对参赛者可见的评测集 |
| 盲测集 | 对参赛者不可见的评测集 |
| 基准智能体（Baseline） | 用于校准评分刻度的参考智能体 |
| 评分项 | 评测的单一维度 |
| 评分权重 | 各评分项在总分中的占比 |

## 第 2 章 评测设计四原则（核心）

### 2.1 可复现（Reproducibility）

| 要求 | 说明 | 判据 |
| --- | --- | --- |
| P1 环境声明 | 明确评测运行环境 | 存在环境规格说明 |
| P2 数据固定 | 评测集版本锁定 | 存在数据集哈希 |
| P3 流程公开 | 评测流程可被第三方重跑 | 存在流程文档 |
| P4 随机性可控 | 随机种子/温度等参数公开 | 存在参数记录 |

### 2.2 可比较（Comparability）

| 要求 | 说明 | 判据 |
| --- | --- | --- |
| P5 同条件 | 所有参赛者在相同条件下评测 | 存在统一条件说明 |
| P6 基准校准 | 有基准智能体提供分数参照 | 存在基准分数 |
| P7 量纲统一 | 评分量纲统一，可跨届比较 | 存在评分标准 |

### 2.3 防作弊（Anti-Gaming）

| 要求 | 说明 | 判据 |
| --- | --- | --- |
| P8 盲测机制 | 存在对参赛者不可见的评测集 | 存在盲测集 |
| P9 权重保密 | 具体权重/阈值不公开 | 权重未公开 |
| P10 过拟合检测 | 检测对公开集的过拟合 | 存在泛化测试 |
| P11 提交去重 | 检测抄袭/近似提交 | 存在查重机制 |

### 2.4 可申诉（Appealability）

| 要求 | 说明 | 判据 |
| --- | --- | --- |
| P12 结果可查 | 参赛者可查询自己的详细得分 | 存在明细反馈 |
| P13 申诉通道 | 存在结果申诉入口 | 存在受理流程 |
| P14 复评机制 | 争议可触发复评 | 存在复评能力 |

## 第 3 章 公开集 / 盲测集分离（红线）

本规范的核心红线：公开集与盲测集必须物理隔离，且盲测集不得以任何形式泄露。

| 评测集 | 可见性 | 用途 | 占比建议 |
| --- | --- | --- | --- |
| 公开集 | 参赛者可见 | 供参赛者自测、调试 | ≤ 40% |
| 盲测集 | 参赛者不可见 | 正式评分 | ≥ 60% |
| 对抗集 | 参赛者不可见 | 检测鲁棒性/边界行为 | 独立计分 |

> 红线：

> 1. 盲测集内容不得出现在任何参赛者可访问的文档、代码、示例中。

> 2. 公开集分数不得直接作为最终成绩，仅作参考。

> 3. 盲测集须在评测结束后版本封存，供后续复评使用。

## 第 5 章 评测流程与申诉

### 5.1 标准流程

作品提交（哈希锁定） → 环境校验 → 公开集自测 → 盲测集评分 → 对抗集测试 → 结果计算 → 结果公示 → 申诉期 → 终版发布

### 5.2 申诉处理

| 环节 | 要求 |
| --- | --- |
| 受理窗口 | 结果公示后设定明确申诉期（建议 ≥ 7 天） |
| 受理范围 | 流程违规、环境异常、计算错误 |
| 不受理 | 对评分标准本身的异议（须在赛前提出） |
| 处理时限 | 明确答复时限 |
| 复评独立性 | 复评人不应为原评审 |

### 5.3 结果封存

| 项 | 要求 |
| --- | --- |
| 封存内容 | 盲测集、评分明细、原始日志 |
| 封存期限 | 建议 ≥ 2 年 |
| 调取条件 | 争议处理、学术复现、审计 |
