# 自治智能体结算治理规范（Open Specification v0.1）

> 发布方：SynomosAI Governance Line

## 〇、一句话摘要

> 让自治智能体"能花钱"这件事，从"敢不敢给它权限"变成"每一分钱都花得清、追得到、退得回"。

---

## 第 1 章 范围与术语

### 1.1 适用范围

本规范适用于任何代表人类执行或提议执行资源支出决策的自治智能体系统，包括但不限于：

- 个人助理型智能体（代购、代订、代付）
- 企业采购型智能体（服务采购、算力采购）
- 设备触发型智能体（耗材补货、自动续费）
- 多智能体协作中的资金流转环节

不适用：纯人类发起的支付、无智能体参与的传统自动化扣款。

### 1.2 术语定义

| 术语 | 定义 |
| --- | --- |
| 万有节点（Omni-Node） | 统一接入硬件与软件、承载治理与结算能力的智能体运行节点 |
| 合理结算 | 同时满足"能付 / 敢付 / 付得清 / 退得回"四道闸门的支出行为 |
| 结算门禁 | 支出执行前的强制性治理校验环节 |
| 支出凭证 | 记录一笔支出的完整成因、凭据与执行痕迹的不可篡改记录 |
| 提议-确认分离 | 智能体只能"提议"支出，最终"确认"权归属人类 |

## 第 2 章 四道闸门模型（核心）

本规范以四道闸门作为合理结算的判定框架。

### 2.1 能付（Capability Gate）

| 要求 | 说明 | 符合性判据 |
| --- | --- | --- |
| C1 通道合规 | 使用持牌机构提供的支付通道 | 通道来源可查证 |
| C2 卡片化确认 | 支付指令以可交互卡片呈现，非文本直出 | 存在确认界面 |
| C3 凭据隔离 | 支付凭据不暴露给智能体推理链 | 凭据不出现在上下文/日志 |

> 说明：本规范不涉及支付通道本身的技术实现，仅规范治理要求。支付业务合规由持牌机构负责。

### 2.2 敢付（Judgment Gate）

| 要求 | 说明 | 符合性判据 |
| --- | --- | --- |
| J1 支出意图可判定 | 每笔支出有明确的意图陈述 | 存在意图字段 |
| J2 权限边界校验 | 支出前校验是否在授权额度/类目内 | 存在边界记录 |
| J3 收款方核验 | 对收款方标识做核验（防钓鱼/错付） | 存在核验步骤 |
| J4 不可判定即不放行 | 无法判定合规性的支出，默认拒绝并升级人工 | 存在默认拒绝逻辑 |

> J4 直接引用治理判定论（GDD）："不可判定，则不可治理"。

### 2.3 付得清（Evidence Gate）

| 要求 | 说明 | 符合性判据 |
| --- | --- | --- |
| E1 凭证链完整 | 每笔支出生成凭证，含：什么/为什么/多少/给谁/何时 | 凭证字段齐备 |
| E2 不可篡改 | 凭证具备完整性校验（哈希/指纹） | 存在指纹字段 |
| E3 可追溯 | 凭证与发起意图、执行过程可关联 | 存在关联标识 |
| E4 可对账 | 支持按时间/类目/主体导出对账 | 存在导出能力 |

### 2.4 退得回（Reversibility Gate）

| 要求 | 说明 | 符合性判据 |
| --- | --- | --- |
| R1 争议可受理 | 存在争议受理入口 | 存在受理记录 |
| R2 证据可复放 | 争议时可完整复现支出全过程 | 存在复放能力 |
| R3 回滚路径明确 | 明确哪些支出可回滚、如何回滚 | 存在回滚说明 |
| R4 不可逆支出须前置强确认 | 不可回滚的支出须双重确认 | 存在强确认逻辑 |

## 第 3 章 提议-确认分离原则（红线）

本规范的核心红线：智能体可以"提议"支出，但不得独立完成"确认"。

| 支出额度档 | 确认要求 |
| --- | --- |
| 微额（低于阈值 T1） | 智能体可执行，事后通知 |
| 小额（T1 ~ T2） | 智能体提议，人类一键确认 |
| 中额（T2 ~ T3） | 智能体提议 + 说明理由，人类确认 |
| 大额（高于 T3） | 双重确认 + 人工复核 |
| 不可逆支出 | 无论金额，一律强确认 |

> 阈值 T1/T2/T3 由采用方根据自身风险偏好设定，本规范不规定具体数值。

## 第 5 章 争议处理与回滚

### 5.1 争议处理流程

争议受理 → 凭证调取 → 过程复放 → 责任判定 → 处置 → 回归档案

### 5.2 责任判定序（引用价值裁决序论）

当争议涉及多方冲突时，依以下优先序判定：

1. V1 人的可归责性 —— 最终确认的人承担首要责任
2. V2 不可逆性设防 —— 不可逆支出的设防义务优先审查
3. V3 证据可复放 —— 证据链完整性作为次要判据

| 支付监管 | 本规范只规范治理要求，支付业务合规由持牌机构负责 | 不替代支付牌照义务 |
